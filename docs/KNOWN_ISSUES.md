# 已知问题与限制

本页以成功构建后的实际反馈为界。静态通过没有使以下运行问题自动消失。

| 问题 | 已有观察 | 尚未证明 / 未完成 |
| --- | --- | --- |
| 动画卡顿 | 用户报告下拉通知栏、打开应用再退出明显卡顿 | 未确认 GPU、调度、频率或合成链中的根因，未验证修复 |
| 5 GHz Wi-Fi | 网络可见但连接失败；2.4 GHz 正常 | 路由器默认小米设置；WPA2/WPA3 是猜测，信道/频宽未知 |
| WPA3/SAE | 所选 Ath12k userspace 路径接入 WPA2-PSK，未接入 SAE | 不能由此断言所有混合模式必然失败，也未证明这次失败就是 SAE |
| 镜像入口差异 | 用户报告八 DTB 变体进入系统 | 原单 DTB 版没有本次进入系统观察；具体 DTB/ABL 匹配根因未确认 |
| 安装软件 / jailbreak | 配置已集成 AppSync 适配 | 未实测 IPA 安装；完整 jailbreak bootstrap、Sileo/deb 流程未完成 |
| corecrypto | 原 archive 编译、POST 字段密封与静态 HMAC检查有记录 | runtime POST 实际执行未验证，许可不自动覆盖普通移植/分发 |
| strict code 空间 | 成功布局 overlap=0 | headroom=0；后续代码或编译器变化可能再次跨页 |
| 新设备首次安装 | 原工具存在 --init-data 接口 | run 41 使用旧 Seed，新身份/新 Seed 的完整重建未复现 |
| 官方二进制对齐 | 对比了固定官方源码共同祖先 | 没取得并证明与作者发布 boot 字节一致 |

`loadable=false`、`runtime_qualified=false` 等原记录字段保留其原含义，不因构建绿色改为 true。用户报告进入系统是一项实际观察，不等于所有驱动、安装、休眠、数据完整性或长期稳定性都已测试。

本次任务只整理教程；没有继续修驱动、刷设备或声称上述问题已经解决。
